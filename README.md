# FarsiFlow برای Coddy

افزونهٔ مرورگر Manifest V3 برای ترجمهٔ رابط آموزشی **Coddy** به فارسی. دامنهٔ هدف عمداً به `coddy.tech` و زیردامنه‌های HTTPS آن محدود شده است؛ این نسخه برای سایت‌های دیگر فعال نمی‌شود.

> ترجمهٔ واقعی با API سازگار OpenAI انجام می‌شود و به کلید API خودتان نیاز دارد. ترجمه به‌طور پیش‌فرض خاموش است؛ تا وقتی کاربر ترجمه یا ترجمهٔ خودکار را فعال نکند، محتوای صفحه به سرویس بیرونی فرستاده نمی‌شود. کد و محیط اجرای Coddy با قواعد DOM حذف می‌شوند.

## معماری

- **Manifest V3 + Vite:** دو صفحهٔ افزونه (popup و options)، content script مستقل و service worker مستقل؛ خروجی content script به‌صورت IIFE بسته‌بندی می‌شود تا Chrome و Edge آن را به‌عنوان اسکریپت کلاسیک اجرا کنند.
- **Popup React:** تشخیص دامنهٔ جاری، ترجمه/بازگردانی، وضعیت، RTL و ترجمهٔ خودکار Coddy.
- **Content:** پیمایش تدریجی text nodeها، استثناهای کد و فرم، صف دسته‌ای، `MutationObserver` برای محتوای پویا و SPA، و نگه‌داری مرجع متن اصلی برای بازگردانی بدون جایگزینی عناصر یا از دست‌دادن event listenerها.
- **RTL manager:** تنظیم زبان/جهت فارسی و حفظ اجزای کدنویسی، فرم‌ها و عناصر دارای `dir` اصلی؛ فقط attributeها و کلاس‌هایی که افزونه اضافه می‌کند هنگام بازگردانی حذف می‌شوند.
- **Background service worker:** تنها بخش دارای دسترسی به کلید API؛ درخواست‌های دسته‌ای را به endpoint سازگار OpenAI می‌فرستد، پاسخ JSON را اعتبارسنجی می‌کند و برای خطاهای موقت تا سه بار با backoff تلاش می‌کند.
- **Cache:** IndexedDB محلی بر مبنای متن اصلی؛ بدون تاریخچهٔ وب‌گردی.
- **Options:** endpoint، مدل، کلید، کیفیت، واژه‌نامهٔ اصطلاحات و پاک‌کردن cache.

### ساختار مهم پروژه

```text
public/manifest.json, content.css
src/
  background/service-worker.ts
  content/{content,translation-manager,exclusion-rules,rtl-manager}.ts
  core/{language-detector,translation-cache}.ts
  popup/                 React popup
  options/               داشبورد تنظیمات
  shared/types.ts
  styles/app.css
vite*.config.ts          خروجی جداگانهٔ UI، content و worker
```

## وابستگی‌ها

- React و React DOM، TypeScript، Vite و پلاگین React
- Tailwind CSS برای پایهٔ استایل و Lucide React برای آیکون‌ها
- `@types/chrome` و Vitest برای آزمون‌های قواعد فیلتر و provider

## برنامه و پوشش MVP

1. ساخت Manifest V3 با دسترسی محدود به Coddy و صفحات تنظیمات افزونه.
2. ساخت popup فارسی برای تشخیص تب، اقدام ترجمه/بازگردانی، RTL و auto.
3. پیاده‌سازی اسکن DOM تدریجی، فیلتر کد/فرم، صف ۱۶تایی و MutationObserver برای SPA و محتوای جدید.
4. اتصال امن service worker به API سازگار OpenAI؛ اعتبارسنجی خروجی، retry/backoff و فاصلهٔ حداقلی میان درخواست‌ها.
5. افزودن IndexedDB با cache پروفایل‌محور، صفحهٔ تنظیمات، واژه‌نامه و دستورالعمل نصب.
6. اجرای typecheck/build و آزمون‌های واحد فیلتر و provider؛ آزمون تعاملی نهایی در Coddy به‌صورت دستی انجام می‌شود.

## نصب توسعه و build

نیازمندی: Node.js 20 LTS، 22 LTS یا 24+ و npm (Vitest 4 نیازمند نسخه‌های LTS پشتیبانی‌شده است).

```bash
npm install
npm test
npm run typecheck
npm run build
```

خروجی نهایی در `dist/` قرار می‌گیرد؛ **همان پوشه** را به مرورگر معرفی کنید.

### بارگذاری در Chrome یا Edge

1. اجرا کنید: `npm install && npm run build`.
2. در Chrome آدرس `chrome://extensions/` یا در Edge آدرس `edge://extensions/` را باز کنید.
3. Developer mode را روشن و **Load unpacked** را انتخاب کنید.
4. پوشهٔ `dist/` را انتخاب کنید.
5. وارد Coddy شوید و آیکون FarsiFlow را بزنید. برای اولین بار، از Settings یک endpoint، نام مدل و API key معتبر ثبت کنید.
6. دسترسی اتصال به میزبان endpoint در صفحهٔ تنظیمات افزونه درخواست می‌شود؛ آن را تأیید کنید. سپس «ترجمهٔ این صفحه» را بزنید.

برای تغییر کدها، دوباره `npm run build` اجرا کنید و در صفحهٔ افزونه دکمهٔ Reload را بزنید. ممکن است لازم شود تب Coddy را هم تازه‌سازی کنید.

## استفاده و حریم خصوصی

- ترجمهٔ خودکار به‌صورت پیش‌فرض غیرفعال است. اگر روشنش کنید، ترجمه در بازدیدهای بعدی Coddy نیز شروع می‌شود.
- متن‌های واجد شرایط برای ترجمه به ارائه‌دهندهٔ انتخابی شما فرستاده می‌شوند. متن ترجمه‌شده به شکل متن ساده در text node نوشته می‌شود؛ HTML یا JavaScript اجرا نمی‌شود.
- کلید در `chrome.storage.local` نگه‌داری می‌شود و هرگز به content script داده نمی‌شود؛ این ذخیره‌سازی محلی **رمزنگاری اختصاصی افزونه نیست** و امنیت پروفایل/دستگاه مرورگر به عهدهٔ کاربر است.
- کد، ادیتورها، ترمینال، ورودی‌ها، فیلدهای رمز، نواحی contenteditable، آدرس‌ها، شناسه‌های شبیه کد و تعدادی از رشته‌های حاوی ایمیل/کلید دسترسی حذف می‌شوند. قواعد شامل تگ‌ها و کلاس‌های رایج Coddy/ویرایشگرهاست.
- cache فقط روی دستگاه است و از صفحهٔ تنظیمات پاک می‌شود. تاریخچهٔ مرور یا تاریخچهٔ ترجمه نگه‌داری نمی‌شود.
- اگر API key نداشته باشید، افزونه عمداً از ترجمهٔ ساختگی یا دیکشنری نمونه استفاده نمی‌کند و خطای راهنمای تنظیمات نشان می‌دهد.

## آزمون

`npm test` آزمون‌های واحد برای فیلتر رشته‌های طبیعی در برابر شناسه‌ها، کد، URL، دستور و داده‌های حساس را اجرا می‌کند. برای آزمون دستی:

1. صفحهٔ Coddy را باز کنید و ابزارهای توسعه را روی یک تمرین شامل متن آموزشی، editor، terminal و نمونه‌کد باز نگه دارید.
2. ترجمه را روشن کنید؛ متن درس باید ترجمه شود و کد/editor/terminal و عملکرد دکمه‌ها باید ثابت بماند.
3. کد را اجرا کنید، منو/گفت‌وگو باز کنید یا محتوای جدید بارگذاری کنید؛ متن جدید باید به‌صورت دسته‌ای ترجمه شود.
4. «بازگرداندن متن اصلی» را بزنید؛ متن DOM قبلی و جهت اصلی برگردد.
5. API key خالی/نامعتبر و محدودیت سرویس را آزمایش کنید؛ پیام خطا باید نمایش یابد و صفحه قابل استفاده بماند.

## محدوده و محدودیت‌های این نسخه

این build روی Coddy متمرکز است؛ API ترجمهٔ سازگار OpenAI، cache، صف پویا، تنظیم auto/RTL و اصطلاحات فعال‌اند. Google Translate/DeepL، مدل محلی، Web Worker، پروفایل چندسایتی و دیکشنری آفلاین در این نسخه پیاده نشده‌اند. فیلتر کد عمداً محافظه‌کار است، ولی چون ساختار Coddy ممکن است تغییر کند، هرگز نمی‌توان برای محتوای ناشناختهٔ صفحه تضمین مطلق داد؛ پیش از استفادهٔ حساس، با تمرین‌های مدنظر بررسی کنید.
